# Aaditya Srivastava — AI portfolio

A responsive portfolio built with plain HTML, CSS, and JavaScript. Open `index.html` in a browser; there is no build step or framework.

## What’s included

- Three selected projects: EvalForge (in progress), voice-controlled cursor navigation, and AI agent experiments.
- A minimalist black interface with custom CSS illustrations, responsive navigation, and scroll reveals.
- An interactive banner that cycles through the three project themes, plus direct email contact.
- Keyboard focus styles and reduced-motion support.

EvalForge is described as in progress because its public repository currently has a single initial commit and is actively being developed. The portfolio describes only the capabilities documented in its README: LLM tracing, experiment runs, evaluation, comparisons, and RAG evaluation.

## Personalize it

1. Update the intro and about copy in `index.html` as your focus and projects evolve.
2. Edit the three project cards, descriptions, and GitHub links in the project section.
3. Update the email address in the contact section if it changes.
4. Adjust the colors and typography in the custom properties near the top of `styles.css`. Google Fonts load online; system fonts are used as fallbacks.

The page is static and can be hosted on any static-site host.
